# Техдолги

1. Добавить sitemap.xml.
2. Добавить favicon и иконки для браузера.
3. Добавить canonical / metadataBase в `app/layout.tsx`.
4. Добавить JSON-LD schema `Organization` / `LocalBusiness`.
5. Проверить, что все якоря навигации (#home, #services, #about, #contact) реально существуют и работают.
6. Убедиться, что `robots.txt` и `sitemap.xml` отражают актуальные страницы.
7. Проверить доступность (alt, contrast, keyboard navigation).
8. Минимизировать client-side JS там, где он не нужен.
