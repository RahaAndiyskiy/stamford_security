# Техдолги

1. Добавить sitemap.xml.
2. Добавить favicon и иконки для браузера.
3. Добавить canonical / metadataBase в `app/layout.tsx`.
4. Добавить JSON-LD schema `Organization` / `LocalBusiness`.
5. Проверить, что все якоря навигации (#home, #services, #about, #contact) реально существуют и работают.
6. Убедиться, что `robots.txt` и `sitemap.xml` отражают актуальные страницы.
7. Проверить доступность (alt, contrast, keyboard navigation).
8. Минимизировать client-side JS там, где он не нужен.

# Статус выполнения

- `app/layout.tsx` — metadataBase, canonical, Open Graph, Twitter metadata, JSON-LD `Organization`/`LocalBusiness` реализованы глобально для всех страниц.
- `robots.txt` — файл существует и разрешает весь сайт.
- `Home` — основная SEO-разметка выполнена.
- `About` — используется тот же глобальный layout, поэтому metadata/JSON-LD также действуют на этой странице.
- Остаётся: `sitemap.xml`, favicon/иконки, проверка `contact` якоря, audit доступности, оптимизация client-side JS.
